# Changelog — Scientific Editor (Agent Skill)

Version history moved here from `SKILL.md` §4 in v5.1, to bring the skill body closer to the Agent Skills recommendation of instructions under 5000 tokens (agentskills.io/specification); v5.2 moved the draft-mode procedure to `references/draft.md`, which brings the body to about the recommended size by estimate (4.2–5.0 k tokens; no tokenizer was run).

- **v5.2 (2026-11-17; released 2026-11-18 UTC, DOI 10.5281/zenodo.24330003):** voice pass widened from classic academic style to the register of each genre, with a catalogue of канцелярит and template patterns and their replacements (`references/voice.md`) and three new rules — no template echo, natural is not invented, read aloud to this reader; `mse_style.py` counts contrast frames, summary tails, attributions without a citation, split predicates and uniform paragraph length, and a longer list of stock phrases; applied genres — grant applications (with the funder's rules, including any on AI tools, read before drafting), monographs, research reports (ГОСТ 7.32-2017), technical documentation, popular science, talk and business presentations, cover letters and responses to reviewers (`references/genres-applied.md`, outlines in `assets/outlines.md`); `mse_genre.py` genres `grant`, `report`, `popsci` and hype words; rubric dimensions that do not apply to a genre marked N/A and left out of the mean; the review-edits procedure and the validation record moved to `references/` to keep the skill body short; tests 43. Edition 2 (17 November 2026, after an external review): a statement on tools used to prepare a text is now a venue-compliance item — checked only where the venue or funder requires one and the author used such tools, never inferred from style, never added unasked, never a score cap; the voice markers are called template patterns, and the skill states that they say nothing about who wrote a text; «мы» / "we" follows the venue's register; contrast frames limited, not banned; markers listed in §0; the Level-2 check and Gate C share one classification per claim; a Gate C override may correct a classification but not waive a trigger; fabricated or falsified data → `reject` once established, suspicion → FLAG; conference proceedings and dissertation tiers named unambiguously; the NIH rule dated by receipt date and date of check; draft mode moved to `references/draft.md`; provenance note removed from `SKILL.md` and `README.md` (author's decision). Edition 3 (17 November 2026): first run of the tools on two of the author's manuscripts (`references/validation.md`); fixes with regression tests — numbered headings with subtitles, overclaim phrases, prepositions not counted as repeated openers, stock phrases by density, only parenthetical clauses counted as glue, the УДК line skipped, incomplete reference records flagged, URL slashes not taken for « // »; 52 tests. Edition 4 (17 November 2026): language check in Russian, English and Japanese (§1e, `references/language.md`, report section L); Japanese as a working language (norms: the journal, then 「公用文作成の考え方」 2022; SIST 02 for references); new `mse_grammar.py` for mechanical slips; Japanese headings, cue words, overclaims and abstracts in characters in `mse_genre.py`; 参考文献 / 引用文献 and «1)» entries in `mse_lint.py`; `mse_style.py` says its word-based markers do not apply to Japanese; 59 tests. CI: Python 3.9 runs on ubuntu-24.04, because ubuntu-latest (26.04) has no Python 3.9 build.
- **v5.1 (2026-11-17; not released separately — included in v5.2):** editorial-recommendation table completed — a Gate C trigger alone and dimensions below the venue bar now have an outcome (rule approved by the author on 17 November 2026); 10-point summary marked as a 2–10 linear rescale; AI-use disclosure grounded in the current ICMJE Recommendations (section V, January 2026) and the COPE statement of 13 February 2023; Kobak et al. 2025 cited with DOI and with the corpus-level caveat; tool usage, tests and known limits moved from Appendix T to `references/tools.md`, with a short pointer left in Appendix T; tool fixes — `mse_genre.py` reads abstracts and keyword lists whose label stands on its own line and no longer takes «следует отметить» for an implication, `mse_lint.py` skips section, figure and table numbers, `mse_style.py` no longer counts "US" as the authorial "us"; report template lists `draft` mode and all genres; venue calibration: «conference volume (РИНЦ/ВАК)» split — a РИНЦ conference volume keeps its bar, a journal on the ВАК list uses the nearest tier with the choice recorded; README: the earlier clinical protocol marked as historical, its worked example no longer invents values absent from the input (kept as a skeleton of `[DATA_REQUIRED]` slots by design — a filled-in example would need invented values), data-governance wording reconciled with the install routes, AI use disclosed; CITATION.cff abstract brought up to date; changelog moved to this file; tests 35 (four regression tests added).
